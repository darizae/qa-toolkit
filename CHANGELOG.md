# Changelog

## 0.1.0 — 2026-11-22

Initial open-source release.

- API surface discovery from local OpenAPI/Swagger JSON files.
- Per-operation, nine-question contract worksheet for allowed/forbidden actors, conditions, relationships, effects, observations and failure modes.
- Compiler for reviewed QA stories to deterministic indexed test case IDs and Markdown/JSON registry.
- Static case-ID reference audit for Python, JavaScript and TypeScript test files (candidate matches only).
- Local MCP stdio server exposing discovery, case compiler, audit and capability tools.
- Portable Agent Skill with question-first QA workflow.
- MIT license, synthetic example API and public README with CLI/MCP/agent setup.

This release does not implement autonomous test execution, claims of passing integration tests, remote MCP hosting or evidence-report rendering. It is designed for QA planning and case traceability.
